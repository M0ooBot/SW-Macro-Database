# Import a standalone AP214 STEP solid as a new native part

Run the packaged C# script `convert-step-part` with an existing STEP file in
`source`, an existing output directory in `output`, and one new `.SLDPRT`
filename in `fileName`. This profile has zero native model targets. The source
must be outside the output tree and the SW-Agent data root. The output tree
must be on the backup volume.

The current profile recognizes plain AP214 Part 21 single-part exchanges up
to 64 MiB, with one advanced BREP shell and a limited vocabulary covering
planar and cylindrical faces, lines and circles. Evidence covers a
SolidWorks AP214 export in that subset. The worker refuses an existing
destination, multiple solids, assembly relationships, external references,
and entity families outside the supported profile. The attached SolidWorks
session must be empty so interrupted recovery can distinguish a clean restart
from a possible residual.

The worker only loads a byte-verified private STEP copy. It journals the
application preferences and possible hidden unsaved import, stages the native
part, and verifies the solid and the absence of linked references after an
independent hidden reopen. It publishes only after closing the hidden model
and checking the inputs, backups and output tree. Use the returned change ID
to request confirmed undo. Undo removes the generated file after backing it up.
Undo of that restore can republish the exact generated bytes.

After a worker interruption, recovery preserves any possibly residual document
while ownership is uncertain, including visible and saved documents. The
recovery report names the candidate and further worker jobs wait. The released
`convert-step` folder scanner retains its dry-run behavior.
